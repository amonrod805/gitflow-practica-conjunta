Este repositorio servirá como demostración de las prácticas estudiadas anteriormente sobre la **filosofía GitFlow**

Las prácticas aplicadas serán:
1. La **creación** del **repositorio**
2. La **creación** de la rama *develop* desde **main**
3. Edición del fichero **README** explicando el proyecto *(o sea este)*
4. **Dos features** creados en su correspondientes ramas
5. Una **rama release**
6. Una **rama hotfix**

Contendrá un *historial* de commits **limpio** y **descriptivo** junto con *merge commits* visibles que muestren las fusiones entre ramas, al igual que **tags** de versión en *main* así como **pull request** cerrados y capturas del **grafo de ramas** usando:
```bash
git log --graph --oneline --all
```
