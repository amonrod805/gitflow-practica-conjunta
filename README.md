## README

En este proyecto hemos hecho una *simulación* de una **página** **web** con su *landing page*, *login* y *home*

Para ello hemos hecho diversas ramas utilizando la filosofía **GitFlow**:

- **main** (donde están el código final del proyecto)
- **develop** (donde se encuentra el código en producción)
- **feature** (donde se van desarrollando cada funcionalidad del proyecto, habrá tantos *features* como funcionalidades)
- **release** (donde se publican los cambios finales en *main*)
- **hotfix** (donde se corrigen errores urgentes *ya publicados* en el *main*)
